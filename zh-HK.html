由接入到業務整合

只需三步，為產品加入編輯功能。

載入元件後，透過屬性、方法及事件連接業務。

  1. 01

    載入檔案，加入標籤

    將元件檔案加入項目、載入指令碼，並在需要編輯內容的位置加入標籤。

  2. 02

    設定所需功能

    透過 custom、insert 等屬性設定工具列及插入選單，清單次序即顯示次序。

  3. 03

    連接你的業務資料

    用 value 讀寫 HTML，透過 change 監聽內容變更，連接儲存、載入及發佈流程。

<script src="https://passer-by.com/widget-editor/dist/widget-editor.min.js"></script> <widget-editor id="editor" language="zh-HK" name="content" custom="heading,fontSize,bold,italic,color,link,insert" insert="image,table,emoji" image="upload,url,resource" ></widget-editor> <script> const editor = document.querySelector('#editor'); editor.value = '<p>開始編輯內容</p>'; editor.addEventListener('change',function(event){ console.log(event.detail.value); }); </script>
常用設定 以屬性設定編輯體驗
屬性 用途 範例
value 讀寫 HTML 內容的 JS 屬性 editor.value = '<p>文章內容</p>';
text 讀取純文字的唯讀 JS 屬性 const text = editor.text;
placeholder 編輯區域空白時的提示文字 placeholder="請輸入文章內容……"
height 編輯區域高度，預設 480px height="520"
custom 工具列功能及排列次序 custom="heading,bold,italic,insert"
heading 標題選單的選項及次序 heading="p,h1,h2,h3"
fontfamily 字型選單的選項及次序 fontfamily="default,yahei,simsun,kaiti"
fontsize 字型大小選單的選項及次序，數字不加 px fontsize="14,16,18,24,36"
alignment 文字及儲存格的對齊選項及次序 alignment="left,center,right,justify"
insert 允許插入的內容類型及次序 insert="image,table,code"
image / video / audio / attachment 各類媒體的插入方式 image="upload,url,resource"
*-limit 上載及素材選取數量上限，空值表示不限 image-limit="9"
language 簡體中文、香港繁體中文或英語介面 language="zh-HK"
view 狀態列的檢視操作及次序 view="source,fullscreen,mobile"
name 原生表單提交使用的欄位名稱 name="content"
form 關聯表單的 id，可用於表單外的元件 form="article-form"
disabled 停用編輯及操作 disabled
required 啟用表單必填驗證 required
常用方法 內容讀寫及編輯操作
方法用途範例
getHTML()讀取目前的 HTML 內容const html = editor.getHTML();
setHTML(value)設定 HTML 內容editor.setHTML('<p>文章內容</p>');
focus()將焦點移至編輯區域editor.focus();
command(name,value)在目前選取範圍執行編輯指令editor.command('bold');
openInsertDialog(type,mode)從外部入口開啟資源插入對話框editor.openInsertDialog('image','resource');
// 讀取及設定內容 editor.setHTML('<p>新的文章內容</p>'); const html = editor.getHTML(); const text = editor.text; // 重用編輯指令 editor.command('bold'); editor.command('heading','h2'); editor.command('insertTable',{rows:3,columns:4}); // 從外部入口開啟插入對話框 editor.openInsertDialog('image','resource');
常用事件 連接內容及資源服務
事件觸發時機event.detail
ready元件首次初始化完成無
change內容變更或執行編輯指令後value HTML、text 純文字
upload選取檔案並通過驗證後files、type、limit、onComplete、onError、onProgress
add在素材庫選取上載檔案後與 upload 相同
request進入素材庫或載入下一頁時type、page、limit、onComplete、onError
remove按下素材移除按鈕時type、url、limit、onComplete、onError
editor.addEventListener('change',function(event){ const {value,text} = event.detail; console.log(value,text); });

上載或新增完成後呼叫 onComplete(list)，清單次序須與 files 一致；request 以 onComplete(list,hasNext) 回傳目前分頁，page 由 1 開始；remove 在業務系統成功刪除後呼叫 onComplete()。失敗時呼叫 onError(error)，上載進度則呼叫 onProgress(percent)。

上載及素材庫 沿用現有資源服務

選取檔案後觸發 upload；素材庫上載觸發 add，回呼格式相同。傳入檔案一律為陣列，回傳 URL 的次序須與檔案次序一致。

async function upload(event){ const {files,type,onComplete,onError,onProgress} = event.detail; try{ const data = new FormData(); files.forEach(file => data.append('files',file)); data.append('type',type); const response = await fetch('/api/upload',{method:'POST',body:data}); if(!response.ok){throw new Error('上載失敗');} const result = await response.json(); onProgress(100); onComplete(result.urls); }catch(error){ onError(error); } } editor.addEventListener('upload',upload); editor.addEventListener('add',upload); editor.addEventListener('request',async function(event){ const {type,page,onComplete,onError} = event.detail; try{ const response = await fetch('/api/materials?type='+type+'&page='+page); if(!response.ok){throw new Error('素材載入失敗');} const result = await response.json(); onComplete(result.items,result.hasNext); }catch(error){ onError(error); } });

介面路徑僅供接入示範，請換成自己的服務。素材支援 URL 或 {original,thumbnail}；hasNext 為 true 時，捲動至底部會自動請求下一頁。素材移除由業務系統透過 remove 事件處理。
