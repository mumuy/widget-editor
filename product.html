从接入到业务集成

三步，把编辑能力放进产品。

无需专用构建流程。
引入组件后，通过属性、方法和事件完成业务连接。

  1. 01

    引入文件，放置标签

    将组件文件放入项目，引入脚本，在需要编辑内容的位置使用标签。

  2. 02

    配置需要的功能

    通过 custom、insert 等属性设置工具栏与插入菜单，列表顺序即显示顺序。

  3. 03

    连接你的业务数据

    用 value 读写 HTML，通过 change 监听内容变化，对接保存、回填与发布流程。

<script src="./dist/widget-editor.min.js"></script> <widget-editor id="editor" name="content" custom="heading,fontSize,bold,italic,color,link,insert" insert="image,table,emoji" image="upload,url,resource" ></widget-editor> <script> const editor = document.querySelector('#editor'); editor.value = '<p>开始编辑内容</p>'; editor.addEventListener('change',function(event){ console.log(event.detail.value); }); // 保存时读取 editor.value，或通过 FormData 获取。 </script>
常用配置 用属性定义编辑体验
属性用途示例
height编辑区域高度，默认 480pxheight="520"
custom工具栏功能及排列顺序custom="heading,bold,italic,insert"
insert允许插入的内容类型及顺序insert="image,table,code"
image / video / audio / attachment各类媒体的插入方式image="upload,url,resource"
*-limit上传及素材选择数量上限，空值表示不限image-limit="9"
language简体中文、香港繁体中文或英语界面language="zh-CN"
view状态栏的视图操作及顺序view="source,fullscreen,mobile"
name原生表单提交使用的字段名称name="content"
上传与素材库 沿用已有资源服务

选择文件后触发 upload；素材库上传触发 add，回调格式一致。传入的文件始终为数组，返回 URL 的顺序需与文件顺序一致。

async function upload(event){ const {files,type,onComplete,onError,onProgress} = event.detail; try{ const data = new FormData(); files.forEach(file => data.append('files',file)); data.append('type',type); const response = await fetch('/api/upload',{method:'POST',body:data}); if(!response.ok){throw new Error('上传失败');} const result = await response.json(); onProgress(100); onComplete(result.urls); }catch(error){ onError(error); } } editor.addEventListener('upload',upload); editor.addEventListener('add',upload); editor.addEventListener('request',async function(event){ const {type,page,onComplete,onError} = event.detail; try{ const response = await fetch('/api/materials?type='+type+'&page='+page); if(!response.ok){throw new Error('素材加载失败');} const result = await response.json(); onComplete(result.items,result.hasNext); }catch(error){ onError(error); } });

接口路径为接入示例，请替换为自己的服务。素材支持 URL 或 {original,thumbnail}；hasNext 为 true 时，滚动到底部自动请求下一页。素材移除通过 remove 事件交由业务侧处理。

内容与命令 界面之外，也能灵活调用
// 读取与设置内容 editor.value = '<p>新的文章内容</p>'; const html = editor.value; const text = editor.text; // 复用编辑命令 editor.command('bold'); editor.command('heading','h2'); editor.command('insertTable',{rows:3,columns:4}); // 从外部入口打开插入弹框 editor.openInsertDialog('image','resource');
