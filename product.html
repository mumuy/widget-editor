产品特征

覆盖常用编辑需求，也方便与你已有的系统集成。

常用编辑功能齐备

标题、列表、引用、表格、多语言代码高亮和媒体插入，让内容清晰，也让表达更丰富。

样式隔离，减少冲突

基于 Shadow DOM 隔离内部样式，减少宿主页面的 CSS 干扰，让编辑器自然融入已有系统。

按需配置功能与菜单

按需设置工具栏、菜单项、插入方式及数量限制，为不同角色和业务场景配置合适的编辑界面。

接入上传服务与素材库

通过事件对接现有文件服务。支持批量上传、缩略图预览和素材分页，存储与访问权限由业务侧管理。

HTML 读写与表单提交

以标准 HTML 读写内容，支持原生表单关联。保存、回填与展示接入现有流程，无需专用内容协议。

单文件接入，无运行时依赖

使用原生 JavaScript 与 Web Component，一个文件包含组件逻辑和样式，无需第三方运行时。

使用方法

引入组件，通过属性配置界面，再用方法和事件连接业务数据。

  1. 01

    引入文件，放置标签

    将组件文件放入项目，引入脚本，在需要编辑内容的位置使用标签。

  2. 02

    配置需要的功能

    通过 custom、insert 等属性设置工具栏与插入菜单，列表顺序即显示顺序。

  3. 03

    连接你的业务数据

    用 value 读写 HTML，通过 change 监听内容变化，对接保存、回填与发布流程。

快速接入 / HTML + JavaScript
<script src="./dist/widget-editor.min.js"></script>

<widget-editor
    id="editor"
    name="content"
    custom="heading,fontSize,bold,italic,color,link,insert"
    insert="image,table,emoji"
    image="upload,url,resource"
></widget-editor>

<script>
    const editor = document.querySelector('#editor');
    editor.value = '<p>开始编辑内容</p>';
    editor.addEventListener('change',function(event){
        console.log(event.detail.value);
    });
    // 保存时读取 editor.value，或通过 FormData 获取。
</script>
常用配置 用属性定义编辑体验
属性用途示例

insert允许插入的内容类型及顺序insert="image,table,code"

上传与素材库 沿用已有资源服务

选择文件后触发 upload；素材库上传触发 add，回调格式一致。传入的文件始终为数组，返回 URL 的顺序需与文件顺序一致。

async function upload(event){
    const {files,type,onComplete,onError,onProgress} = event.detail;
    try{
        const data = new FormData();
        files.forEach(file => data.append('files',file));
        data.append('type',type);
        const response = await fetch('/api/upload',{method:'POST',body:data});
        if(!response.ok){throw new Error('上传失败');}
        const result = await response.json();
        onProgress(100);
        onComplete(result.urls);
    }catch(error){
        onError(error);
    }
}
editor.addEventListener('upload',upload);
editor.addEventListener('add',upload);

editor.addEventListener('request',async function(event){
    const {type,page,onComplete,onError} = event.detail;
    try{
        const response = await fetch('/api/materials?type='+type+'&page='+page);
        if(!response.ok){throw new Error('素材加载失败');}
        const result = await response.json();
        onComplete(result.items,result.hasNext);
    }catch(error){
        onError(error);
    }
});

接口路径为接入示例，请替换为自己的服务。素材支持 URL 或 {original,thumbnail}；hasNext 为 true 时，滚动到底部自动请求下一页。素材移除通过 remove 事件交由业务侧处理。

内容与命令 界面之外，也能灵活调用
// 读取与设置内容
editor.value = '<p>新的文章内容</p>';
const html = editor.value;
const text = editor.text;

// 复用编辑命令
editor.command('bold');
editor.command('heading','h2');
editor.command('insertTable',{rows:3,columns:4});

// 从外部入口打开插入弹框
editor.openInsertDialog('image','resource');
