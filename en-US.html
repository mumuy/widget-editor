    From setup to integration

    Add editing to your product in three steps.

    Use attributes, methods, and events to connect the editor to your workflow.

    1. 01

      Load the file and add a tag

      Add the component file to your project, load the script, and place the tag where you need an editor.

    2. 02

      Choose your features

      Set toolbar and insertion options with attributes such as custom and insert. Their order determines the display order.

    3. 03

      Connect your data

      Read and write HTML with value, and listen for change events to connect saving, loading, and publishing.

    Events Connect content and asset services
    EventWhen it firesevent.detail
    readyAfter the first initializationNone
    changeAfter content changes or an editing commandvalue HTML, text plain text
    uploadAfter files are selected and validatedfiles, type, limit, onComplete, onError, onProgress
    addAfter files are selected for the asset librarySame as upload
    requestWhen opening the asset library or loading another pagetype, page, limit, onComplete, onError
    removeWhen an asset’s remove button is clickedtype, url, limit, onComplete, onError
    editor.addEventListener('change',function(event){ const {value,text} = event.detail; console.log(value,text); });

    Call onComplete(list) after uploading or adding assets, in the same order as files. For request, return the current page with onComplete(list,hasNext); page starts at 1. For remove, call onComplete() after deletion succeeds. Use onError(error) for failures and onProgress(percent) for upload progress.

    Uploads and asset library Use your existing asset services

    Selecting files fires upload; uploading to the asset library fires add. Both use the same callbacks. Files are always an array, and returned URLs must follow the file order.

    async function upload(event){ const {files,type,onComplete,onError,onProgress} = event.detail; try{ const data = new FormData(); files.forEach(file => data.append('files',file)); data.append('type',type); const response = await fetch('/api/upload',{method:'POST',body:data}); if(!response.ok){throw new Error('Upload failed');} const result = await response.json(); onProgress(100); onComplete(result.urls); }catch(error){ onError(error); } } editor.addEventListener('upload',upload); editor.addEventListener('add',upload); editor.addEventListener('request',async function(event){ const {type,page,onComplete,onError} = event.detail; try{ const response = await fetch('/api/materials?type='+type+'&page='+page); if(!response.ok){throw new Error('Could not load assets');} const result = await response.json(); onComplete(result.items,result.hasNext); }catch(error){ onError(error); } });

    Replace the example API paths with your own services. Assets accept a URL or {original,thumbnail}. When hasNext is true, scrolling to the bottom requests the next page. Handle asset deletion through the remove event.
