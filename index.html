    富文本编辑器

    一个标签实现富文本编辑，支持常用的文字排版功能。

    文字格式

    选中文字，可以设置加粗、斜体、下划线、删除线、文字颜色、文字背景、字体和文字大小，也可以通过格式刷复制样式。

    使用上标书写 x2，使用下标书写 H2O。通过 language 属性可切换简体中文、繁体中文和英语界面。

    选中段落后点击块引用，为文章添加引用内容。

    编辑功能

    • 支持 H1 至 H6 标题、块引用和段落对齐
    • 支持有序列表、无序列表、链接和图片、视频、音频、附件插入
    • 支持表格选格插入、行列增删、单元格合并与拆分
    • 支持分割线和多种编程语言的代码块高亮

    使用方法

    1. 在编辑区输入内容
    2. 选中文字，通过工具栏设置格式
    3. 点击源码查看并编辑 HTML

    更多内容请查看项目源码。

    表格示例

    点击单元格可增加或删除行列，拖动或按住 Shift 选择连续单元格后，可合并与拆分单元格。

    快速使用 参数配置 常用方法 事件
    快速使用

    引入组件、设置初始内容，并监听内容变化。

    <script src="./widget-editor.min.js" defer></script> <widget-editor id="editor" placeholder="请输入内容…"> <h2>开始写作</h2> <p>选中文字，通过工具栏调整格式。</p> </widget-editor> <script> customElements.whenDefined('widget-editor').then(function(){ let editor = document.querySelector('#editor'); editor.value = '<p>新的内容</p>'; console.log(editor.value,editor.text); editor.addEventListener('change',function(event){ console.log(event.detail.value,event.detail.text); }); }); </script>
    参数配置

    列表使用英文逗号分隔，顺序即显示顺序，支持动态修改。

    配置示例

    <widget-editor custom="heading,fontSize,bold,italic,color,link,insert" insert="image,table,emoji" heading="p,h2,h3" fontsize="14,16,20,24" image="upload,url,resource" image-limit="9" view="source,fullscreen"> </widget-editor>
    属性 说明 默认值
    value JS 属性：读写 HTML，设为空字符串可清空内容 标签内的初始内容
    text JS 属性：读取纯文本，只读 随内容生成
    placeholder 空白时的提示文字 在这里开始写作…
    height 编辑区域高度，单位 px，范围 160～2000 480
    language 界面语言：zh-CN 简体、zh-HK 繁体、en-US 英语 zh-CN
    name 表单提交字段名，提交值为 HTML 空字符串
    form 关联表单的 id，用于表单外的组件 最近的父级表单
    disabled 禁用编辑和操作，不参与表单提交及校验 不设置
    required 启用必填校验，图片等非文本内容也有效 不设置

    value、text 通过 JavaScript 访问；其他项目通过组件属性配置。布尔属性存在即生效。

    属性 说明 默认值
    custom 工具栏功能及顺序；撤销、重做固定显示 完整工具栏
    insert 插入菜单中的功能及顺序 divider,table,image,video,attachment,audio,emoji,code
    view 底部操作及顺序：源码、全屏、手机模式 source,fullscreen,mobile
    heading 标题菜单的选项及顺序 p,h1,h2,h3,h4,h5,h6
    fontfamily 字体菜单的选项及顺序 全部字体，见可选值
    fontsize 字号菜单的选项及顺序，数字不带 px 12,14,16,18,20,24,28,32,36,48
    alignment 对齐菜单：左、中、右、两端对齐 left,center,right,justify

    未设置时使用默认值。设置为空可隐藏对应菜单；custom="" 仅保留撤销与重做。

    属性 说明 默认值
    image 图片允许的插入方式及顺序 upload,url,resource
    video 视频允许的插入方式及顺序 upload,url,iframe,resource
    audio 音频允许的插入方式及顺序 upload,url,resource
    attachment 附件允许的插入方式及顺序 upload,url,resource
    image-limit 每次上传或选择图片的数量上限 1
    video-limit 每次上传或选择视频的数量上限 1
    audio-limit 每次上传或选择音频的数量上限 1
    attachment-limit 每次上传或选择附件的数量上限 1

    *-limit 默认为单选，正整数表示上限，空值表示不限数量，同时约束上传和素材库选择。媒体方式为空则禁用该类型插入。

    常用方法

    读取当前内容的 HTML。

    let html = editor.getHTML(); console.log(html);

    设置 HTML，传入空字符串可清空内容，不触发 change。

    editor.setHTML('<p>新的内容</p>');

    打开媒体插入弹框，沿用当前光标或选区。省略 mode 时打开该类型配置的第一种方式，无法打开时返回 null。

    参数 说明
    type image 图片、video 视频、audio 音频、attachment 附件
    mode upload 上传、url 网络地址、resource 素材库；iframe 仅适用于视频，方式须在媒体属性中开放
    editor.openInsertDialog('image','upload'); editor.openInsertDialog('video','iframe'); editor.openInsertDialog('audio','url'); editor.openInsertDialog('attachment','resource');

    将焦点移到编辑区域。

    editor.focus();
    原生表单
    <form id="article-form"> <widget-editor name="content" required></widget-editor> <button type="submit">保存</button> </form> <script> document.querySelector('#article-form').onsubmit = function(event){ event.preventDefault(); let html = new FormData(this).get('content'); console.log(html); }; </script>

    设置 name 即可提交 HTML，支持必填校验、禁用和重置。表单外的组件用 form="表单id" 关联。

    事件

    事件通过 event.detail 提供数据，并支持冒泡。上传与素材管理由业务页面处理。

    组件首次加入页面并初始化完成时触发，无 detail 数据。监听后再将组件加入页面。

    let editor = document.createElement('widget-editor'); editor.addEventListener('ready',function(){ console.log(editor.value); }); document.body.appendChild(editor);

    用户编辑内容或执行编辑操作时触发。程序设置 value 或调用 setHTML() 不触发此事件。

    detail 字段 说明
    value 当前 HTML
    text 当前纯文本
    editor.addEventListener('change',function(event){ let {value,text} = event.detail; console.log(value,text); });

    选择文件并通过校验后触发。业务上传成功后返回素材数组，数量和顺序须与 files 一致；用户确认后插入。

    detail 字段 说明
    files File[]，单文件也是数组
    type image、video、audio、attachment
    limit 上传或选择的数量上限；不限数量时为 Infinity
    onComplete(items) 成功时返回素材数组，支持 URL 字符串或 {original,thumbnail}
    onError(error) 失败时传入 Error 或错误消息
    onProgress(percent) 更新上传进度，范围 0～100

    示例接口接收 files 和 type，返回 {urls: [...]}。处理函数可由 upload 和 add 共用。

    let editor = document.querySelector('#editor'); async function upload(event){ let {files,type,onComplete,onError} = event.detail; let data = new FormData(); files.forEach(file=>data.append('files',file)); data.append('type',type); try{ let response = await fetch('/api/upload',{method:'POST',body:data}); if(!response.ok){throw new Error('上传失败');} let result = await response.json(); onComplete(result.urls); }catch(error){ onError(error); } } editor.addEventListener('upload',upload); editor.addEventListener('add',upload);

    切换到素材库时触发；若素材库是配置的第一项，打开弹框即请求。返回数组用于展示，空数组表示暂无素材。

    detail 字段 说明
    type image、video、audio、attachment
    limit 上传或选择的数量上限；不限数量时为 Infinity
    onComplete(items) 成功时返回素材数组，支持 URL 字符串或 {original,thumbnail}
    onError(error) 失败时传入 Error 或错误消息
    editor.addEventListener('request',async function(event){ let {type,onComplete,onError} = event.detail; try{ let response = await fetch('/api/materials?type='+encodeURIComponent(type)); if(!response.ok){throw new Error('素材加载失败');} let result = await response.json(); onComplete(result.urls); }catch(error){ onError(error); } });

    在素材库点击“上传素材”并选择文件后触发，参数与 upload 相同，可共用上传处理函数。成功后新素材显示在列表前面，仍需用户确认插入。

    detail 字段 说明
    files File[]，单文件也是数组
    type image、video、audio、attachment
    limit 上传或选择的数量上限；不限数量时为 Infinity
    onComplete(items) 成功时返回素材数组，支持 URL 字符串或 {original,thumbnail}
    onError(error) 失败时传入 Error 或错误消息
    onProgress(percent) 更新上传进度，范围 0～100
    // upload 为 upload 标签页示例中的上传处理函数。 editor.addEventListener('add',upload);

    点击素材右上角的移除按钮时触发。业务删除成功后调用 onComplete() 更新列表，不影响文档中已插入的内容。

    detail 字段 说明
    type image、video、audio、attachment
    limit 上传或选择的数量上限；不限数量时为 Infinity
    url 待移除素材的原地址
    onComplete() 移除成功，无需传参
    onError(error) 移除失败时传入 Error 或错误消息
    editor.addEventListener('remove',async function(event){ let {type,url,onComplete,onError} = event.detail; try{ let response = await fetch('/api/materials',{ method:'DELETE', headers:{'Content-Type':'application/json'}, body:JSON.stringify({type,url}) }); if(!response.ok){throw new Error('素材移除失败');} onComplete(); }catch(error){ onError(error); } });
    素材格式

    上传、新增和加载素材均支持以下格式：缩略图用于预览，原图用于插入；省略缩略图时使用原地址。

    onComplete([ 'https://example.com/photo.jpg', { original:'https://example.com/original.jpg', thumbnail:'https://example.com/thumbnail.jpg' } ]);
    文件限制
    类型 支持格式 单个文件上限
    图片 PNG、JPEG、GIF、WebP 5 MB
    视频 MP4、WebM、Ogg 50 MB
    音频 MP3、WAV、Ogg、M4A、AAC、FLAC、WebM 20 MB
    附件 任意文件 20 MB

    回调仅生效一次；关闭弹框或更改相关权限后，未完成回调失效。演示页使用本地文件读取，不上传服务器。
