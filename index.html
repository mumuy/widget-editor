    富文本编辑器

    一个标签实现富文本编辑，支持常用的文字排版功能。

    文字格式

    选中文字，可以设置加粗、斜体、下划线、删除线、文字颜色、文字背景、字体和文字大小，也可以通过格式刷复制样式。

    使用上标书写 x2，使用下标书写 H2O。通过 language 属性可切换简体中文、繁体中文和英语界面。

    选中段落后点击块引用，为文章添加引用内容。

    编辑功能

    • 支持 H1 至 H6 标题、块引用和段落对齐
    • 支持有序列表、无序列表、链接和图片、视频、音频、附件插入
    • 支持表格选格插入、行列增删、单元格合并与拆分
    • 支持分割线和多种编程语言的代码块高亮

    使用方法

    1. 在编辑区输入内容
    2. 选中文字，通过工具栏设置格式
    3. 点击源码查看并编辑 HTML

    更多内容请查看项目源码。

    表格示例

    点击单元格可增加或删除行列，拖动或按住 Shift 选择连续单元格后，可合并与拆分单元格。

    参数说明

    在组件上设置以下属性；未设置时使用默认值。列表使用英文逗号分隔，配置顺序就是显示顺序，重复值和不支持的值会被忽略。

    属性含义默认值
    name 原生表单提交时的字段名，提交内容为编辑器的 HTML。 空字符串
    form 关联表单的 id，可让表单外的编辑器参与提交。 最近的父级表单
    disabled 禁用编辑和工具栏操作，不参与表单提交及校验。 不设置（可编辑）
    required 要求填写内容；空白文字和空段落无效，图片等非文本内容有效。 不设置（非必填）
    placeholder 空白编辑器中的提示文字。 在这里开始写作…
    height 编辑区域高度，单位为 px，允许 160～2000； 480
    language 界面语言：zh-CN 简体中文、zh-HK 香港繁体中文、en-US 英语。 zh-CN
    heading 标题菜单的选项及顺序，p 为正文，h1～h6 为标题。 p,h1,h2,h3,h4,h5,h6
    fontfamily 字体菜单的选项及顺序，例如 yahei（微软雅黑）、simsun（宋体）。
    全部 13 种预设字体default,yahei,simsun,simhei,kaiti,fangsong,pingfang,dengxian,stsong,stkaiti,stxihei,sourceSans,sourceSerif
    fontsize 字号菜单的选项及顺序，只填写支持的数字，不加 px。 12,14,16,18,20,24,28,32,36,48
    alignment 对齐菜单的选项及顺序。 left,center,right,justify
    custom 工具栏功能及顺序。撤销和重做固定显示。
    默认工具栏heading,fontFamily,fontSize,alignment,indentation,bold,italic,underline,strikethrough,superscript,subscript,color,backgroundColor,blockquote,orderedList,unorderedList,link,format,formatPainter,insert
    insert 插入菜单的功能及顺序，custom 中的独立插入按钮仍可使用。 divider,table,image,video,attachment,audio,emoji,code
    view 底部操作按钮及顺序。设为空隐藏按钮，字数统计保留；custom 中的同名功能仍可使用。 source,fullscreen,mobile
    image 图片允许的插入方式及标签顺序。 upload,url,request
    video 视频允许的插入方式及标签顺序。 upload,url,iframe,request
    audio 音频允许的插入方式及标签顺序。 upload,url,request
    attachment 附件允许的插入方式及标签顺序。 upload,url,request
    image-bind 点击该 ID 的外部节点唤起图片插入弹框，不加 #。 空字符串
    video-bind 点击该 ID 的外部节点唤起视频插入弹框，不加 #。 空字符串
    attachment-bind 点击该 ID 的外部节点唤起附件插入弹框，不加 #。 空字符串
    audio-bind 点击该 ID 的外部节点唤起音频插入弹框，不加 #。 空字符串
    image-batch 每次上传或从资源库选择图片数量上限，填写正整数；空值不限数量。 1
    video-batch 每次上传或从资源库选择视频数量上限，填写正整数；空值不限数量。 1
    attachment-batch 每次上传或从资源库选择附件数量上限，填写正整数；空值不限数量。 1
    audio-batch 每次上传或从资源库选择音频数量上限，填写正整数；空值不限数量。 1
    upload / request 事件

    图片、视频、音频和附件选择文件并确认插入后，会触发 upload 事件。组件负责插入和显示进度，文件由你的页面上传。

    event.detail说明
    files按选择顺序排列的 File[]，单文件也使用数组。
    type文件类型：image、video、audio 或 attachment。
    limit本次允许的最大资源数量，未限制时为 Infinity。
    onComplete(urls)全部成功后，按文件顺序传入数量相同的地址数组，整批插入原来的光标或选区位置。
    onError(err)上传失败时传入 Error 或错误消息，在弹框内显示，用户可重试。
    onProgress(percent)更新整批上传进度，传入 0～100 的百分比。

    下面使用原生 XMLHttpRequest 上传文件并报告进度。请按实际接口修改地址和响应字段。

    let editor = document.querySelector('#editor'); editor.addEventListener('upload',function(event){ let {files,type,onComplete,onError,onProgress} = event.detail; let request = new XMLHttpRequest(); request.open('POST','/api/upload'); request.responseType = 'json'; request.upload.onprogress = function(event){ if(event.lengthComputable){ onProgress(event.loaded/event.total*100); } }; request.onload = function(){ if(request.status>=200&&request.status<300&&Array.isArray(request.response?.urls)){ onComplete(request.response.urls); }else{ onError(request.response?.message||'上传失败，请重试'); } }; request.onerror = ()=>onError('网络错误，请重试'); request.onabort = ()=>onError('上传已取消'); let data = new FormData(); files.forEach(file=>data.append('files',file)); data.append('type',type); request.send(data); });

    使用 image="upload,url,request" 等属性配置资源库入口。点击「选择资源」触发 request 事件，其 detail 包含 type、limit、onComplete(urls)、onError(err)。数量限制沿用对应的 *-batch 属性，未限制时为 Infinity。

    外部资源库关闭后，调用 onComplete([url]) 插入资源；取消或失败调用 onError(err) 恢复插入弹框。此事件不包含文件和进度回调。演示页的资源库可选择本页已上传的同类文件。

    editor.addEventListener('request',async function(event){ let {type,limit,onComplete,onError} = event.detail; try{ // 自行实现资源库，关闭界面后返回 URL 数组。 let urls = await openResourceLibrary({type,limit}); if(!urls?.length){ onError('已取消选择'); return; } onComplete(urls); }catch(error){ onError(error); } });
    关于富文本编辑器

    富文本编辑器可以在编辑文字时设置字体、颜色、大小和段落样式，并插入链接、图片和表格。通过标题、列表和段落对齐，让内容具有清晰的层次；通过格式刷复用文字样式，让排版保持一致。编辑器同时提供 HTML 源代码查看和编辑功能，适用于文章、公告和日常笔记等内容的编辑。
