    从接入到业务集成

    仅需三步，把编辑能力放进产品。

    引入组件后，通过属性、方法和事件完成业务连接。

    1. 01

      引入文件，放置标签

      将组件文件放入项目，引入脚本，在需要编辑内容的位置使用标签。

    2. 02

      配置需要的功能

      通过 custom、insert 等属性设置工具栏与插入菜单，列表顺序即显示顺序。

    3. 03

      连接你的业务数据

      用 value 读写 HTML，通过 change 监听内容变化，对接保存、回填与发布流程。

    <script src="https://passer-by.com/widget-editor/dist/widget-editor.min.js"></script> <widget-editor id="editor" name="content" custom="heading,fontSize,bold,italic,color,link,insert" insert="image,table,emoji" image="upload,url,resource" ></widget-editor> <script> const editor = document.querySelector('#editor'); editor.value = '<p>开始编辑内容</p>'; editor.addEventListener('change',function(event){ console.log(event.detail.value); }); </script>
    常用配置 用属性定义编辑体验
    属性 用途 示例
    value 读写 HTML 内容的 JS 属性 editor.value = '<p>文章内容</p>';
    text 读取纯文本的只读 JS 属性 const text = editor.text;
    placeholder 编辑区域为空时的提示文字 placeholder="请输入文章内容……"
    height 编辑区域高度，默认 480px height="520"
    custom 工具栏功能及排列顺序 custom="heading,bold,italic,insert"
    heading 标题菜单的选项及顺序 heading="p,h1,h2,h3"
    fontfamily 字体菜单的选项及顺序 fontfamily="default,yahei,simsun,kaiti"
    fontsize 字号菜单的选项及顺序，数字不带 px fontsize="14,16,18,24,36"
    alignment 文字及单元格的对齐选项及顺序 alignment="left,center,right,justify"
    insert 允许插入的内容类型及顺序 insert="image,table,code"
    image / video / audio / attachment 各类媒体的插入方式 image="upload,url,resource"
    *-limit 上传及素材选择数量上限，空值表示不限 image-limit="9"
    language 简体中文、香港繁体中文或英语界面 language="zh-CN"
    view 状态栏的视图操作及顺序 view="source,fullscreen,mobile"
    name 原生表单提交使用的字段名称 name="content"
    form 关联表单的 id，可用于表单外的组件 form="article-form"
    disabled 禁用编辑及操作 disabled
    required 启用表单必填校验 required
    常用方法 内容读写与编辑操作
    方法用途示例
    getHTML()读取当前 HTML 内容const html = editor.getHTML();
    setHTML(value)设置 HTML 内容editor.setHTML('<p>文章内容</p>');
    focus()聚焦编辑区域editor.focus();
    command(name,value)在当前选区执行编辑命令editor.command('bold');
    openInsertDialog(type,mode)从外部入口唤起资源插入弹框editor.openInsertDialog('image','resource');
    // 读取与设置内容 editor.setHTML('<p>新的文章内容</p>'); const html = editor.getHTML(); const text = editor.text; // 复用编辑命令 editor.command('bold'); editor.command('heading','h2'); editor.command('insertTable',{rows:3,columns:4}); // 从外部入口打开插入弹框 editor.openInsertDialog('image','resource');
    常用事件 连接内容与资源服务
    事件触发时机event.detail
    ready组件首次初始化完成无
    change内容变化或执行编辑命令后value HTML、text 纯文本
    upload选择文件并通过校验后files、type、limit、onComplete、onError、onProgress
    add在素材库选择上传文件后与 upload 相同
    request进入素材库或加载下一页时type、page、limit、onComplete、onError
    remove点击素材移除按钮时type、url、limit、onComplete、onError
    editor.addEventListener('change',function(event){ const {value,text} = event.detail; console.log(value,text); });

    上传与新增完成后调用 onComplete(list)，列表顺序与 files 一致；request 使用 onComplete(list,hasNext) 返回当前页，page 从 1 开始；remove 在业务删除成功后调用 onComplete()。失败调用 onError(error)，上传进度调用 onProgress(percent)。

    上传与素材库 沿用已有资源服务

    选择文件后触发 upload；素材库上传触发 add，回调格式一致。传入的文件始终为数组，返回 URL 的顺序需与文件顺序一致。

    async function upload(event){ const {files,type,onComplete,onError,onProgress} = event.detail; try{ const data = new FormData(); files.forEach(file => data.append('files',file)); data.append('type',type); const response = await fetch('/api/upload',{method:'POST',body:data}); if(!response.ok){throw new Error('上传失败');} const result = await response.json(); onProgress(100); onComplete(result.urls); }catch(error){ onError(error); } } editor.addEventListener('upload',upload); editor.addEventListener('add',upload); editor.addEventListener('request',async function(event){ const {type,page,onComplete,onError} = event.detail; try{ const response = await fetch('/api/materials?type='+type+'&page='+page); if(!response.ok){throw new Error('素材加载失败');} const result = await response.json(); onComplete(result.items,result.hasNext); }catch(error){ onError(error); } });

    接口路径为接入示例，请替换为自己的服务。素材支持 URL 或 {original,thumbnail}；hasNext 为 true 时，滚动到底部自动请求下一页。素材移除通过 remove 事件交由业务侧处理。
