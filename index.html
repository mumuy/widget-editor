    富文本编辑器

    一个标签实现富文本编辑，支持常用的文字排版功能。

    文字格式

    选中文字，可以设置加粗、斜体、下划线、删除线、文字颜色、字体和文字大小，也可以通过格式刷复制样式。

    使用上标书写 x2，使用下标书写 H2O。通过 language 属性可切换简体中文、繁体中文和英语界面。

    选中段落后点击块引用，为文章添加引用内容。

    编辑功能

    • 支持 H1 至 H6 标题、块引用和段落对齐
    • 支持有序列表、无序列表、链接和图片、视频、音频、附件插入
    • 支持表格选格插入、行列增删、单元格合并与拆分
    • 支持分割线和多种编程语言的代码块高亮

    使用方法

    1. 在编辑区输入内容
    2. 选中文字，通过工具栏设置格式
    3. 点击源码查看并编辑 HTML

    更多内容请查看项目源码。

    表格示例

    点击单元格可增加或删除行列，拖动或按住 Shift 选择连续单元格后，可合并与拆分单元格。

    参数说明

    在 <widget-editor> 标签上设置以下属性；未设置时使用默认值。列表使用英文逗号分隔，配置顺序就是显示顺序，重复值和不支持的值会被忽略。

    属性含义默认值用法示例
    name 原生表单提交时的字段名，提交内容为编辑器的 HTML。未设置或为空时不提交。 空字符串 name="content"
    form 关联表单的 id，可让表单外的编辑器参与提交。 最近的父级表单 form="article-form"
    disabled 布尔属性，禁用编辑和工具栏操作，不参与表单提交及校验。父级 fieldset 的禁用也会生效。 不设置（可编辑） <widget-editor disabled></widget-editor>
    required 布尔属性，要求填写内容；空白文字和空段落无效，图片等非文本内容有效。 不设置（非必填） <widget-editor name="content" required></widget-editor>
    placeholder 空白编辑器中的提示文字。未自定义时，提示会随界面语言变化。 在这里开始写作… placeholder="请输入文章内容……"
    height 编辑区域高度，单位为 px，允许 160～2000；填写数字即可。 420 height="360"
    language 界面语言：zh-CN 简体中文、zh-HK 香港繁体中文、en-US 英语。 zh-CN language="en-US"
    heading 标题菜单的选项及顺序，p 为正文，h1～h6 为标题。空值隐藏菜单。 p,h1,h2,h3,h4,h5,h6 heading="p,h2,h3"
    fontfamily 字体菜单的选项及顺序，例如 yahei（微软雅黑）、simsun（宋体）、kaiti（楷体）。空值隐藏菜单。
    全部 13 种预设字体default,yahei,simsun,simhei,kaiti,fangsong,pingfang,dengxian,stsong,stkaiti,stxihei,sourceSans,sourceSerif
    		 fontfamily="yahei,simsun,kaiti"
    fontsize 字号菜单的选项及顺序，只填写支持的数字，不加 px。空值隐藏菜单。 12,14,16,18,20,24,28,32,36,48 fontsize="14,16,24,36"
    alignment 对齐菜单的选项及顺序：left 左对齐、center 居中、right 右对齐、justify 两端对齐。空值隐藏菜单。 left,center,right,justify alignment="left,center,right"
    custom 工具栏功能及顺序，可把图片、视频等插入功能直接放到工具栏。撤销和重做固定显示；空值仅保留这两个按钮。
    默认工具栏heading,fontFamily,fontSize,alignment,indentation,bold,italic,underline,strikethrough,superscript,subscript,color,blockquote,orderedList,unorderedList,link,format,formatPainter,insert
    		 custom="heading,bold,italic,image,insert"
    insert 插入菜单的功能及顺序。空值隐藏插入菜单；custom 中的独立插入按钮仍可使用。 divider,table,image,video,attachment,audio,emoji,code insert="table,image,emoji"
    image 图片允许的插入方式及标签顺序：upload 上传文件、url 填写地址。空值禁用图片插入。 upload,url image="url"
    video 视频允许的插入方式及标签顺序，支持 upload、url 和第三方视频 iframe。空值禁用视频插入。 upload,url,iframe video="upload,url,iframe"
    audio 音频允许的插入方式及标签顺序，支持 upload、url。空值禁用音频插入。 upload,url audio="url,upload"
    attachment 附件允许的插入方式及标签顺序，支持 upload、url。空值禁用附件插入。 upload,url attachment="upload"

    custom 控制工具栏是否显示某个功能；heading、fontfamily、fontsize、alignment 控制其下拉菜单的选项。移除属性可恢复默认值，运行时可通过 editor.setAttribute('fontsize','16,24,36') 调整配置。

    编辑器支持原生表单提交、重置和校验，使用 new FormData(form).get('content') 可读取 name="content" 的 HTML 内容。布尔属性存在即生效，取消时应移除属性，不能使用 disabled="false"。

    选择上传文件时，组件通过 upload 事件交给外部处理上传。完整的字体字段、工具栏字段和上传接入示例请查看 使用文档。

    关于富文本编辑器组件

    富文本编辑器可以在编辑文字时设置字体、颜色、大小和段落样式，并插入链接、图片和表格。通过标题、列表和段落对齐，让内容具有清晰的层次；通过格式刷复用文字样式，让排版保持一致。编辑器同时提供 HTML 源代码查看和编辑功能，适用于文章、公告和日常笔记等内容的编辑。
