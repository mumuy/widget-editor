轻量接入

一个标签，即可使用

index.html
<script src="dist/widget-editor.min.js"></script>

<widget-editor
    theme="light"
    height="420"
    placeholder="写下你的想法……">
</widget-editor>

用熟悉的方式操作内容

通过 value 属性读取和设置 HTML；监听 change 事件获取最新内容。

const editor = document.querySelector('widget-editor');
editor.value = '<h2>你好，世界</h2>';
editor.addEventListener('change', function(event){
    console.log(event.detail.value);
});

支持 theme="light / dark" 与 height 属性。完整用法见项目 README。

关于富文本编辑器组件

好的编辑体验，让注意力回到内容本身。这个组件提供常用的文字排版工具，既适合写一篇文章，也适合编辑公告、产品说明和日常笔记。

项目沿用 widget-code 的目录组织和代码风格：组件入口位于 src/widget-editor.js，各项功能独立放在 src/module/，样式与主题放在 src/style/，构建产物放在 dist/。结构清晰，便于阅读与扩展。
